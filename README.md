# Guess the Number

**Guess the Number** é um jogo simples e divertido onde o jogador precisa adivinhar um número gerado aleatoriamente dentro de um intervalo específico. O jogo oferece três níveis de dificuldade para desafiar seus jogadores:

## Níveis de Dificuldade

- **Fácil**: O número está entre 1 e 50, com 6 tentativas para acertar.
- **Médio**: O número está entre 1 e 100, com 10 tentativas para acertar.
- **Difícil**: O número está entre 1 e 200, com 15 tentativas para acertar.

## Objetivo

A cada nível, o jogador recebe um número de tentativas adequado à dificuldade, tornando a experiência mais emocionante e desafiadora. O objetivo é adivinhar o número com o menor número de tentativas possível.

## Como Jogar

1. Escolha o nível de dificuldade (Fácil, Médio ou Difícil).
2. O número gerado aleatoriamente será apresentado no intervalo correspondente.
3. O jogador terá um número limitado de tentativas para acertar o número.
4. O jogo termina quando o jogador acerta o número ou esgota as tentativas.

**Boa sorte e divirta-se!**
